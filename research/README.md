## Deep reverse engineering (one expert agent per strategy)

The premise is that every screened wallet runs a real strategy, so not finding it counts as a failure. Each agent works in iterations of about 75 minutes, for up to about 20 hours per strategy. After every iteration, three fresh-eyes experts propose untried directions. A wall stands only after 10+ hours of work, with the direction catalog closed and three auditors unable to name an untried direction. When an agent claims the target, an independent examiner scores the frozen rule on sealed data, and skeptics try to refute any pass. A failed exam sends its diagnosis back to the agent, and the next exam uses newer data. Workspaces: `reverse_engineering/<strategy>/` (`NOTES.md`, `FINAL_RULE.md`, `EXAM*.md`, `panels/`).
